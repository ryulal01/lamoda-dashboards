# Метрики
Все данные синтетические и не отражают реальные показатели Lamoda.

| Метрика | Определение |
|---|---|
| Views | Просмотры карточек товаров |
| Product clicks | Клики по товарам |
| Add to cart | Добавления в корзину |
| Orders | Условное число заказов |
| Revenue | Синтетическая выручка в рублях |
| CTR | `100 * SUM(product_clicks) / SUM(views)` |
| View-to-order conversion | `100 * SUM(orders) / SUM(views)` |

Период: 1 января — 31 декабря 2024 года. Выручка искусственно рассчитана по количеству заказов и цене товара. Конверсии рассчитаны из агрегированных сумм.
